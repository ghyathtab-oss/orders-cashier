# عداد الطلبات — متاجر الأكواد والألعاب

أداة عربية Mobile First تعمل بالكامل على GitHub Pages بدون Backend.

## المزايا
- 10 قوالب متاجر جاهزة بهويات لونية مختلفة.
- عدّ الطلبات المنفذة بسرعة عبر + و −.
- إضافة/تعديل/حذف المنتجات.
- السعر اختياري، مع حساب تلقائي لقيمة المنتجات المسعّرة.
- بيانات مستقلة لكل متجر.
- حفظ تلقائي محلي عبر `localStorage`.
- أرشفة الوردية وتصفير العدادات مع الاحتفاظ بالكشف في السجل.
- معاينة كشف حساب نهائي وتصديره PNG من Canvas بدون مكتبات خارجية.
- مشاركة الصورة مباشرة على الأجهزة التي تدعم Web Share API.
- واجهة RTL ومصممة أساسًا للموبايل.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات: `index.html`, `styles.css`, `app.js`.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و `/root`.
5. افتح رابط GitHub Pages من هاتفك.

> البيانات تُحفظ داخل متصفح الجهاز نفسه. مسح بيانات المتصفح أو استخدام جهاز آخر لا ينقل السجل تلقائيًا.
